# 小蓝君表情研究所 🌈

一个可爱、温暖的小蓝君系列表情包单页网站。首页以“长时间陪伴”为品牌主题，访客可以浏览、筛选、下载和本地收藏表情包。

![小蓝君表情研究所横幅](public/xiaolanjun-banner.jpeg)

## 主要功能

- 🎨 小蓝君品牌化单页设计，支持电脑和手机屏幕
- 🎈 可爱卡通动效：漂浮标签、跑马灯、卡片弹跳和上传庆祝效果
- 🗂️ 按“全部 / 陪伴 / 开心 / 晚安”分类浏览
- ↓ 公开表情支持单张生成 PNG 下载，访客不需登录
- 📦 所有访客都可一键将整套公开表情打包为 ZIP 下载
- ✎ 表情馆默认的 4 张公开示例也可以改名、改分类、换背景色、修改气泡文字或替换图片
- × 公开示例可删除，并提供“恢复默认示例”功能防止误操作
- ⬆️ 支持点击或拖拽上传 PNG、JPG、WebP 和 GIF
- 🏷️ 上传后可为每张表情填写名字，并选择“陪伴 / 开心 / 晚安”类别
- 🎨 提供蜜桃粉、薄荷绿、晴空蓝、晚安紫和奶油黄 5 种卡片背景
- 💾 使用 IndexedDB 保存到当前浏览器，刷新后仍保留
- ✎ 已收藏表情可以重命名、改类别、换背景色或替换图片
- ↓ 支持下载和删除自己收藏的图片
- 🎁 个人浏览器收藏可导出为 ZIP，方便备份或私下分享给朋友
- ♿ 支持键盘操作和“减少动效”系统设置

> 公开表情包对所有访客可见并可下载。为了适配纯静态的 GitHub Pages，访客个人上传的图片只保存在其当前浏览器设备中，不会自动公开或同步到其他设备。

## 本地运行

需要 Node.js 22.13.0 或更高版本。

```bash
npm install
npm run dev
```

启动后打开终端提示的本地地址。

## 构建与检查

```bash
npm run build
npm run lint
```

## 项目结构

```text
app/
├── page.tsx            # 页面内容、上传与本地收藏交互
└── globals.css         # 品牌视觉、动效与响应式样式
src/
└── main.tsx            # React 入口
public/
└── xiaolanjun-banner.jpeg
.github/workflows/       # GitHub Pages 自动发布
```

## 发布到 GitHub Pages

1. 在 GitHub 中创建仓库并推送本项目。
2. 进入仓库 **Settings → Pages**。
3. 将 **Source** 设为 **GitHub Actions**。
4. 每次推送到 `main` 分支后，页面都会自动更新。
