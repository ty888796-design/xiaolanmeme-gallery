![小蓝君表情研究所横幅](public/xiaolanjun-banner.jpeg)

嗨，我是小蓝君。

这里是我收集日常心情的小小表情馆。开心的时候、想说晚安的时候，或者只是想安静地陪在某个人身边，都可以来这里挑一张表情，把不太好意思直接说出口的话轻轻送出去。

我希望这些表情不只是聊天时的一张图片，也能替你记住那些普通却很重要的时刻。谢谢你来看我，也谢谢你愿意让小蓝君出现在你的聊天框里。

## 这个表情馆可以做什么

- 浏览“陪伴、开心、晚安”等不同分类的小蓝君表情
- 把喜欢的表情单张下载到电脑，聊天时随时使用
- 将整套公开表情打包下载，慢慢收藏
- 上传自己的小蓝君表情，并为它取名字、选择分类
- 为每张表情挑选合适的卡片背景颜色
- 修改已经收藏的表情，包括名称、分类、背景色和图片
- 删除暂时不想保留的表情
- 修改、替换或删除表情馆中原有的示例表情
- 在误删示例后恢复默认内容

## 关于你上传的表情

你上传、修改和收藏的内容会留在当前浏览器里，关闭页面或刷新后仍然可以找到。它们不会自动公开，也不会跑到其他人的设备上。

换一台电脑、换一个浏览器，或者清理浏览器数据后，本地收藏可能会消失。重要的表情记得及时下载，或者导出成 ZIP 留一份备份。

公开表情则可以被每位来访者浏览和下载，方便大家把小蓝君带回自己的聊天日常。

## 在本地打开表情馆

准备好 Node.js 22.13.0 或更高版本，然后运行：

```bash
npm install
npm run dev
```

终端会显示一个本地地址，用浏览器打开它就能看到表情馆。

## 构建与检查

```bash
npm run build
npm run lint
```

## 项目结构

```text
app/
├── page.tsx            # 页面内容、上传和表情管理功能
└── globals.css         # 小蓝君的颜色、卡片、动效和手机适配
src/
└── main.tsx            # 网页入口
public/
└── xiaolanjun-banner.jpeg
.github/workflows/       # GitHub Pages 自动发布
```

## 发布到 GitHub Pages

1. 将项目上传到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中将 **Source** 设为 **GitHub Actions**。
4. 以后每次更新 `main` 分支，GitHub 都会重新发布网页。
